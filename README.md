# AnonAI
bezpieczna, lekka i samowystarczalna aplikacja webowa przeznaczona do lokalnej pseudonimizacji wrażliwych danych przed wysłaniem ich do chmurowych modeli sztucznej inteligencji (LLM, np. ChatGPT, Claude, Gemini), z możliwością natychmiastowego przywrócenia oryginalnych danych (deanonimizacji 1:1) po powrocie odpowiedzi z AI.
