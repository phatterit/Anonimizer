Security model. This page operates strictly locally: the default-src 'none' CSP policy blocks every network request and external resource, nothing is written to disk (no localStorage / sessionStorage / IndexedDB / cookies) — the mapping vault lives solely in this tab's RAM and vanishes when the tab closes or when PANIC (Alt+Shift+X) is triggered. Detection is heuristic — always review the anonymized output before sending and add manual masks where needed. The “residual risk” notice flags potential traces left untouched by the scan; absence of a warning is not a guarantee. Browser extensions (Grammarly, LanguageTool, password managers) and built-in browser AI sidebars (Copilot, Gemini) can read field contents despite CSP — open this page in a clean profile without extensions. Secret length in the table remains hidden until you click “Show”. JavaScript cannot physically zero memory pages: PANIC clears all references, overwrites fields, and pressures GC (best-effort). The OS clipboard manager may keep history outside the browser's reach.
