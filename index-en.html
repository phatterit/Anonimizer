Security model. This page operates strictly locally: the default-src 'none' CSP policy blocks every network request and external resource, nothing is written to disk (no localStorage / sessionStorage / IndexedDB / cookies) — the mapping vault lives solely in this tab's RAM and vanishes when the tab closes or when PANIC (Alt+Shift+X) is triggered. JavaScript cannot physically zero memory pages: PANIC clears all references, overwrites fields, and pressures GC (best-effort).
